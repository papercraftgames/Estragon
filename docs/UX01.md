## GGX text and Boolean syntax

A bare attribute supplies Boolean `true` only to a metadata-validated writable
Bool property: `<HBox wrap>`, `<UiButton disabled>` or `<Text visible>`.
Unknown properties, signals, `key`, `bind:value`, non-Bool properties and duplicate
explicit attributes fail at their authored spans. Ordered `{...props}` retains
its existing semantics: a later spread can override a bare attribute, and a later
bare attribute can override a spread. There is no truthiness conversion.

Literal body text and String expressions supply the existing writable native
String `text` property, including Godot Button and EstragonButton:

```gogo
const Text = preload("../../../addons/estragon/runtime/node/text.gd")
const UiButton = preload("../../../addons/estragon/runtime/node/button.gd")
func heading() -> Element:
    return <Text>Hello {self.username}!</Text>
func action() -> Element:
    return <Button pressed={on_click}>Native Godot button</Button>
```

Use explicit preload paths appropriate to the generated file's location, as in
[the combined gallery](../examples/ux01/UXGallery.gogo). Each interpolation is
evaluated once, in source order. Values must be String; write `str(count)` when
conversion is intended. Quotes, apostrophes, Unicode and punctuation in literal
body text are data, not GDScript string syntax. Braces delimit expressions;
markup delimiters retain their grammar meaning. Inline spaces remain literal.
For multiline bodies, indentation at interior line edges is removed, empty
formatting lines are ignored and nonempty lines join with one space. Newlines
between text and interpolation also contribute one separating space.

There are no implicit Label children. Empty bodies preserve the native default.
Containers can retain formatting whitespace around Element children; meaningful
text on a type without writable String `text`, mixed Element/text bodies and
explicit `text` plus body are errors. A spread supplying `text` conflicts with a
body even when the values match. Dynamic non-String/conflicting descriptions
fail before native writes and retain the last good tree. Ordinary Element child
expressions remain supported on containers. Source spans/maps and native
actual-path semantic validation remain authoritative.

## Available capacity and maximum dimensions

An auto main-axis Wrap can use its immediate parent's definite available content
capacity (minus outer margins) to break lines, while keeping a short group's
natural width. Transparent Gogo roots forward that capacity. It does not become
a definite percentage reference: an otherwise indefinite percentage axis remains
indefinite. Truly unanchored Wrap stays on one line. Ordinary stacks, Grid and
3D do not acquire global shrink or viewport fallback behavior.

Component2D `max_width` and `max_height` accept retained numeric/string Lengths,
including px, immediate-parent percentages and visible viewport/reference units.
`auto` is unbounded; zero is valid. Negative, nonfinite and unsupported unit
specs reject. Omission during reconciliation restores `auto`. The cap constrains
the owner's outer border-box before padding/border consumption. Minima and native
allocation floors win a conflict, with a bounded warning. Margins stay outside.
Stack grow redistributes capacity left by capped siblings; Wrap/Grid use the same
floor/cap contract. Descendants keep their own dimensions and paint/hit beyond
ordinary boxes. A maximum adds neither clipping nor text glyph wrapping.

## Verification

`tools/check-ux01.ts` exercises an immutable direct-Yarn package in its actual
`node_modules` location, both official Linux4.0.4 and pinned Linux4.7.0 only.
It includes exact wrap reproduction, text/Bool negatives, max/visible-overflow
pixels and input, native scroll/nesting/capture/persistence, combined gallery at
320x240/640x480/1000x800, native Inspector undo, both actual Play paths with
invalid unsaved source/repair and cold editor restart. Exact diagnostics must be
inside bounded expected-error brackets; other errors fail. Evidence and failed
attempts are recorded on #183. No physical-keypress gate, release certification,
extra engine/platform or routine CI expansion is part of UX01.

The repository's Gogo source roots include `examples/ux01`. Its reproduction uses
explicit Settings/Rose preload aliases to uniquely named fixture files, avoiding
collisions with other checked-in project components. Source-owned typed Gogo
fields retain their own writable-property metadata rather than being looked up
as fields on the native base class; actual generated-path validation still checks
the resulting assignments. This also preserves ordinary imported component props.
