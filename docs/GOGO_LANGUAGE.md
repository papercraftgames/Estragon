# Gogo and GGX — implemented contract

Gogo is GDScript-like source in .gogo, compiled by the bundled native Godot compiler. GGX is its namespace-free embedded Node composition syntax. Author a GDScript-first module; standalone markup, stage-0 XML/JSON, legacy factory tags and custom child-adders are retired in C4 #83. No external compiler is required by users.

Every GGX element resolves to a constructible native Godot Node, registered Node script class, or explicit top-level const preload alias for a zero-required-argument Node script. Non-Node models/resources remain ordinary property/expression values. Relative imports resolve against generated output location; use explicit res:// paths for portable examples. Ambiguous aliases (including aliases shadowing native Godot classes) fail; unsynchronized imported disk/cache source fails until Godot reloads it. Compilation never instantiates authored classes to discover types.

Canonical framework classes are EstragonRect/Text/Button/HBox/VBox. Use those registered names or explicit aliases as in examples/counter/Counter.gogo. **Button is Godot Button; EstragonButton is Estragon.** Rect/Text/HBox/VBox are not compiler-reserved names and gain no implicit meaning. No transitional *2D widget aliases remain. Ordinary Controls may be composed as ordinary Nodes; they do not become automatic layout participants.

Props/signals use native typed metadata. Quote string/StringName values; write typed values as GDScript expressions in braces (for example width={100.0}, fill={Color(0.2,0.8,0.6)}). Duplicate/unknown/read-only props and reserved owner/script assignment reject. Event attributes require named handler/Callable expressions, never inline anonymous function declarations. Ordinary functions/lambdas may contain GGX. GDScript itself remains the expression/type authority; native semantic failure blocks Play with authored source-map diagnostics.

Children are newly declared Node elements attached with inherited void add_child. Arbitrary expression-child adoption is not implemented. Unrelated factory arguments evaluate once in authored traversal order; explicit reactive self reads follow [T09-B](REACTIVE_GGX.md). Typed static factories preserve lexical scope and source maps. The new subtree receives explicit owners after attachment and persistent signal connections; invalid Callables/connections fail with cleanup. Application-owned Object signal subscriptions use ordinary GDScript lifecycle code. Native Node identity, reparent/free and pack/reload are tested.

Lexical composition retains GDScript strings, comments, multiline strings, comparisons, indentation and CRLF spans without regex rewriting. Code-only non-Node Gogo modules are supported. Godot-version syntax and semantics apply to retained native code; do not claim that syntax unsupported by the selected Godot engine becomes valid through Gogo. Deterministic GDScript and range maps live in a generated sibling directory; editor publication validates actual paths, preserves UIDs/Script identity and rolls back failures.

T09-A [observable properties/models](BINDABLE_PROPERTIES.md) adds lowercase Gogo-only `@bindable` on top-level explicitly typed instance properties, native `<name>_changed(previous, value)` signals and setters. Quiet declaration initialization, native `is_same` equality and synchronous reentrant writes are defined/tested; custom get/set/annotation composition and local/static/inner-class declarations reject explicitly. Code-only RefCounted data models and inherited properties work through the same Godot-only compiler/editor. Ordinary `.gd` annotations are not supported.

T09-B implements bounded reactive GGX properties via explicit self paths, native typed signals and retained target-owned subscriptions; see [contract](REACTIVE_GGX.md).

Not implemented: collections/repeaters, arbitrary expression children/import namespaces, rich text/wrapping, full widgets/style/focus/accessibility and general 3D wrapping. See [UI API](NODE_UI.md), [runtime](NODE_RUNTIME.md), [editor](EDITOR.md) and [testing](TESTING.md). Historical language/compiler reports remain archival facts; they are not supported legacy syntax guarantees.
