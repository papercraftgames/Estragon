## Failures and limits

Original [attempt logs](../../tests/surfaces/evidence/attempts/) remain truthful:
initial pack fixture owners were assigned after helper adoption and did not
persist private ancestry; assigning ordinary scene-root owners before adoption
fixes it. Mixed indentation in the new editor fixture was corrected. First
paired standalone4.0 game timed out because its temporary RefCounted coroutine
owner was not retained; a local probe reference fixes it. The next collector
completed all4.0 native/editor stages, then a new hash assertion incorrectly
assumed4.0 generated script UID sidecars. Supplying the gallery's real committed
UID as fixture metadata tests preservation on both engines. These corrections
change tests/orchestration only after the implementation commit; final paired
acceptance is fully PASS. No failed result was relabeled PASS. Log trailing whitespace/blank EOF lines are normalized; copied
JSON/PNG/manifests retain original bytes.

Manual interactive smoke: **UNTESTED**. Automated native rendering/input,
Inspector/undo/current+main Play/repair/restart ran; physical keypresses are not a
gate. Owner surfaces use16 chords per quarter arc and native polygon rasterization
without extra edge smoothing; fractional square defaults remain pixel-identical.
Child clipping is **rectangular**, not a rounded descendant mask.4.0 optional
isolated-preflight/symlink introspection remain unavailable; mandatory actual-path
validation/rollback passes. The fixture reads baseline PNG data directly and
emits the engine's normal non-export image-load warning; it is not export proof.
No shadows, transitions, style cascade/resource system,3D effects, other
engine/platform or release/publication claim. Owner review/merge remains next.
