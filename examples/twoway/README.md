# Native two-way boolean demo

Run `Demo.tscn`. Click the model/row toggle to edit the same class-wide Gogo model; the label and other controls project its value. Replace model, hide/show rows and reverse keys to exercise native identity and subscriptions. The host flag uses the same binding mechanism. No manual event-to-model handler. See [contract](../../docs/TWO_WAY_BINDINGS.md) for exact syntax, deferred commit and bounded input scope.
