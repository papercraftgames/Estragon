# Native Gogo editor workflow

Enable the bundled Estragon plugin in a Godot project containing the addon. Author GDScript-first .gogo files and run the native Counter or another scene normally. Save and both main/current Play paths compile with Godot alone; no Bun/Node executable, process bridge, setup setting or fallback exists. gogo.config.json source_roots are authoritative; otherwise the plugin scans project source with documented evidence/cache exclusions.

Native lexical highlighting uses the real Gogo editor tab, including saved/unsaved updates. The plugin saves current Gogo buffers before Play even with native autosave disabled. Unsavable files, syntax/type/handler failures block stale execution and report authored spans. Staged multi-file publication validates actual-path semantics, generated code/maps and dependent resources, refreshes existing Scripts in place and restores bytes/maps/timestamps/cache identity on failure. Repairing source recovers normal Play. Stable UIDs and no-op output identity are preserved.

Native GGX descriptions compile at startup before scene restoration; explicit imports allow cold source-only builds without waiting for a specific framework class. Filesystem events still schedule later refreshes. Version/capability bridges preserve documented 4.0 behavior: isolated preflight is unavailable on 4.0.4 but actual-path semantic validation is mandatory. Missing optional reflection never accepts stale code or rejects valid source. Running-application hot reload/new inherited defaults are not promised. The owner-accepted never-associated hidden-tab limitation (#44) remains: reveal and activate the unknown tab to associate highlighting; no PASS/fix claim is made for it.

Tests use self-contained isolated editor settings, actual main/current Play APIs and real child games; they never force-enable the addon or alter user preferences in this checkout. Physical keypress tests are not requirements. Real native graphics evidence is collected separately. The text-file extension preference is global and persists after disabling; preserve existing values and never erase user preferences.

Current automated acceptance: tests/native_ui/editor, tests/ggx/editor and tools/check-native-addon.ts on official 4.0.4/pinned 4.7.0 Linux. See [testing and release policy](TESTING.md), [Gogo language](GOGO_LANGUAGE.md), [demo](NODE_UI.md) and current issue/PR evidence. Completion/navigation, live preview and debugger remapping remain future work.

F04 removes the eager Node/binder backend. The same editor builds one description contract for all GGX and rejects retired Node-returning view declarations before Play. Canonical Counter, 2D/3D/model and structural scenes retain actual-path semantic transactions, maps/UIDs/cache restoration and saved/unsaved main/current Play repair; see [cutover/parity](F04_CUTOVER.md).

For Yarn-acquired addon packages, copy the complete addon to `res://addons/estragon`, add node_modules/.gdignore, then enable `addons/estragon/editor/plugin.cfg` explicitly; dependency installation alone does not register it. [Exact standalone install contract](PACKAGING.md).
