# Reactive GGX — current single composition engine

F04 [#98](https://github.com/resistdesign/Estragon/issues/98) replaces the T09-B static self-path compiler and target-owned binder Nodes after F01–F03 established dynamic getter observation and retained reconciliation. [Cutover inventory and parity](F04_CUTOVER.md). Old T09-B execution outcomes remain historical facts in #86/PR #87 and Git history, not a second supported runtime.

All GGX now produces virtual Element descriptions. A typed `build_view() -> Element` observes actual Gogo getter reads, including ordinary helper calls, locals, model replacement and conditional paths. One external manager coalesces signals, processes parents before nested components, preflights desired output, and changes only declared props/handlers/native structure that differ. It retains native Nodes and native animation/state for unchanged declarations. There are no explicit-self dependency restrictions, generated reader/source methods, property-binding helper children, separate queues or duplicate subscriptions.

Run `examples/reactive/Demo.tscn` for nested Gogo model text/style/width/gap updates; the canonical Counter uses the same path. A computation subscribes once per read object/property signal even when several props use it. Model replacement rewires after safe deferred recomposition; stale reads disconnect, host exit suspends and reentry reconnects, disposal cancels queued work. Independent nested components retain separate scopes. Repeated helpers must be pure; lifecycle/events perform once-only effects. Null models use explicit native conditional fallback values, rather than implicit hidden hold-last semantics.

Native widget setters distinguish paint-only updates and affected-branch layout. Actual Node2D/Node3D/layout/native transforms remain authoritative; #88's expanded transform policy is outside F04. Managed output is transient, authored/foreign scene ownership is separate, and packing/reload reconstructs source-authoritative output once.

`@bindable` signals retain their typed equality/initialization/reentrancy/inheritance semantics. Raw Array/Dictionary in-place writes and ordinary native properties do not magically notify; bindable reference reassignment is supported. [Conditional composition](F02_CONDITIONALS.md), [mapped/keyed arrays](F03_LISTS.md), [bindable model contract](BINDABLE_PROPERTIES.md).

`tools/check-reactive.ts` remains a required strict group. Its native runtime tests verify model replacement/null repair, deduplicated observers, coalescing, retained IDs, native paint/layout, host/leaf lifecycle, pending free cleanup, packed host restoration, helper descriptions and exact source maps. Real editor saved/unsaved main/current Play rejects invalid source and restores code/maps/UIDs/timestamps/cache before repair; rendered before/after/resized captures remain required. Only official Linux 4.0.4 and pinned 4.7.0. Exact results/manual-smoke status live in #98/its sole PR. F05/F06 are not shipped.
