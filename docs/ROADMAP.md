# Roadmap and milestones

Current baseline: bundled native Godot Gogo/GGX compiler/editor, canonical Node2D Rect/Text/Button/HBox/VBox, retained Counter, bounded 2D/3D entries/participants/adapters and a composed event-driven layout core. C1–C3 merged; C4 #83 / PR #84 retires old production classes/shims/JSON/reference tooling and replaces discontinued release gates with addon-relevant native acceptance. Done only upon owner review/merge. Historical proof/C01 reports retain their exact outcomes; see [WORK_STATUS](WORK_STATUS.md), [TESTING](TESTING.md) and live issue/PR.

Next work requires separate owner selection after C4 review. T09 remains Gogo-only lowercase @bindable (including non-Node models), scoped observable dependencies, layout updates, collections/retained keyed Nodes and two-way cycle guards. L01 defines a fuller 2D padding/margin contract on the composed core. Broader widgets, focus/IME/keyboard/touch/accessibility, wrapping/rich text, style/theme/images/clipping/scroll and 3D wrapping require bounded specifications and runnable demos. R02 renderer research is deferred. T10 legacy JSON retirement is incorporated into C4 rather than another live runtime requirement.

Godot 4.0+ is the target; current acceptance is official 4.0.4 and pinned 4.7.0 Linux only. Require real native compiler/runtime/editor/graphics/distribution evidence, preserve genuine failures, never certify untested minors/platforms. Estragon is an addon, not a standalone executable product. One PR total; owner merges manually.
