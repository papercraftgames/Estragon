# Native Gogo indentation (EDIT-01)

[Issue #196](https://github.com/papercraftgames/Estragon/issues/196) adds **Project → Tools → Format Gogo / Auto Indent** for the active authored `.gogo` tab in Godot's Script dock. With its text editor focused, **Cmd+I** (Meta) or **Ctrl+I** invokes the same action. Stock Godot treats Gogo as a TextFile, so its GDScript-only Auto Indent command is not the Gogo command. The addon uses the public tool-menu and input APIs; it does not replace or patch Godot's private Script dock menus.

The command formats the **whole current unsaved buffer**, retaining the selection rather than formatting only selected lines. It reads that CodeEdit's configured tabs/spaces and indentation width. Leading whitespace is the only text it changes: it does not wrap lines, split layout matrix rows, change operators, rewrite literals, save files or compile. Ordinary `.gd`, generated `.gd`, inactive tabs, other text files and generated source maps are outside its edit target.

One native Undo restores the unformatted buffer, including unsaved author edits; Redo reapplies formatting. Carets and selection endpoints follow their source text as indentation changes, including reversed selections and secondary carets. Positions inside indentation clamp to the new indentation. Vertical and horizontal scroll are restored. Formatting an already formatted buffer does not add an undo operation or dirty a clean document. A changed document becomes dirty normally, and Undo can restore its saved version. A change that would merge two carets is refused without editing.

## Grammar and safety bounds

The bundled native lexer/parser identifies GGX tags, attributes, spread/interpolation expressions and layout declarations. Formatting preserves every physical row (including CRLF), meaningful markup text, quoted/triple strings and multiline comment content. Nested paired and self-closing tags, multiline attributes, native delimiters and GDScript blocks receive indentation. Existing GDScript indentation determines suite relationships; the formatter normalizes their widths rather than guessing a different control flow.

Malformed tags/expressions, unfinished strings/delimiters, missing suite indentation and ambiguous dedents produce a Gogo panel diagnostic and leave the entire buffer unchanged. Repair the structure before formatting again. This is an indentation command, not a full GDScript syntax/type validator: normal save/Play still performs actual-path semantic validation through the existing transactional compiler. Some syntactically incomplete but unambiguous native statements may retain their text until that validation. Blank lines and multiline literal continuation rows retain their bytes. No external compiler or formatter process is involved.

## Verification

`tools/check-formatting.ts` runs parser/token/row/idempotence cases (including the owner's original Cmd+I reproduction and real Home/Layouts/Core sources), native CodeEdit undo/redo/dirty/caret/selection/scroll cases, and an isolated real Script dock fixture. The fixture activates the native Tools menu and sends Ctrl/Meta key events through Godot's viewport, exercises multiple/ordinary/generated tabs and plugin disable/re-enable/restart, and runs the same native layout/input probe before and after formatting through both Play entrypoints. Rejected Play must retain generated code, maps, UID, timestamps and cached Script; repaired formatted Play must publish current source/maps. The exact directly installed Yarn payload is checked unchanged on both approved Linux engines. This does not claim an interactive macOS Cmd+I session or a manual visual smoke test.
