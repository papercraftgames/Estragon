# Prepared release notes

## 0.1.0-beta.1 — proposed, unpublished

First curated `@papercraftgames/estragon` native Godot addon artifact after merged F01–F06. Includes bundled Gogo/GGX compiler/editor, typed/class-wide bindables, one signal-driven description reconciler, conditional/keyed retained Nodes, native boolean two-way toggle, layout-first 2D widgets and bounded 3D adapters, opt-in profiling and measured LIS/preflight improvements.

No JavaScript compiler/runtime or lifecycle scripts. Yarn dependency acquisition requires an explicit copy to project addons/estragon and node_modules/.gdignore. Version and actual publication require separate owner approval after packaging PR review. This is a pre-1.0 slice, not full UI framework/release certification. Exact verified source/engines/artifacts and limitations are recorded in issue #104 and the packaging PR.
