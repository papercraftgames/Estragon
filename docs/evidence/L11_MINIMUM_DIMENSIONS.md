# L11 — native 2D minimum dimensions

[#171](https://github.com/papercraftgames/Estragon/issues/171), base `3238dbb`
(merged S02 #170). [Contract](../LENGTHS.md#l11--minimum-2d-dimensions),
[ADR-0022](../DECISIONS.md#adr-0022--native-2d-border-box-minimum-dimensions).

Component2D declares min_width/min_height once. The sole Length parser resolves
units; the existing mathematical core retains authored and native allocation
floors separately and combines them by max. Explicit/intrinsic/allocated sizes
respect that outer border-box floor. Parent-owned StackPolicy consumes it,
including through transparent Gogo roots. No second solver, helper Node, cascade,
new parent policy, max dimension or public 3D field is introduced. Native2D delegates
to the common size/redraw hook without stretching native geometry.
