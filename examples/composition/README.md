# F01 function composition Counter

Enable the bundled addon and run `Counter.tscn`. Ordinary count assignments reexecute its typed `build_view` function automatically; the same native entry/text/buttons are retained. Helper reads track the typed non-Node model. No refresh, manual subscription or hook is authored. This is the static-shape F01 proof, not conditional/list composition.
